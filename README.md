📊 Server_Performance_Stats
Create a script server-stats.sh that can analyze basic server performance statistics.
The script should display:
🖥️ CPU
- Total CPU usage
💾 Memory
- Total memory usage
- Free vs Used
- Usage percentage
📀 Disk
- Total disk usage
- Free vs Used
- Usage percentage
⚡ Processes (CPU)
- Top 5 processes by CPU usage
🧠 Processes (Memory)
- Top 5 processes by memory usage
